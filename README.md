
# Retail Sales Analysis

## Project Overview
This project analyzes retail sales data using Python to understand business performance, customer behavior, and sales trends.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives
- Analyze total sales and revenue.
- Understand customer purchasing behavior.
- Identify top-performing product categories.
- Analyze monthly sales trends.
- Generate meaningful business insights.

## Project Structure
- `data/` – Dataset
- `visualizations/` – Charts and graphs
- `business insights/` – Business findings
- `documentation/` – Project report
- `sales analysis/` – Analysis files

## Key Skills
Data Cleaning, Data Analysis, Data Visualization, Python, Pandas, NumPy.

## Conclusion
This project helped me understand retail sales performance and extract useful business insights using Python.
